# 我的技术学习路线

## 前言

作为一名开发者，保持持续学习和技术输入是不断成长的核心动力。本文记录我的技术学习路线与阶段目标。

## 一、前端与现代工程化

- **基础深度**：深入理解 JavaScript / TypeScript 核心原理、异步编程与事件循环。
- **现代框架**：熟练掌握 Vue 3 生态（Composition API、Pinia、Vite、VitePress）。
- **工程化素养**：模块化、自动化构建、CI/CD 持续集成与部署。

## 二、后端与全栈拓展

- **Node.js**：服务端开发、RESTful API 设计、微服务架构。
- **数据库**：关系型数据库（PostgreSQL/MySQL）与 NoSQL、缓存设计。
- **云计算与容器**：Docker 容器化部署、云原生与 Serverless 实践。

## 三、AI 与新技术探索

- **AI 辅助编程**：深度集成 Agent 编程流，提升工程交付效率。
- **大模型应用**：探索 LLM 应用开发与提示工程。

## 四、总结

学无止境，知行合一。通过持续记录与动手实践，将知识内化为个人能力。
