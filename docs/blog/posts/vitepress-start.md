# 使用 VitePress 快速创建博客

## 前言

今天开始使用 VitePress 搭建自己的个人博客。

## 一、为什么选择 VitePress？

VitePress 具有以下优势：

- 使用 Markdown 编写文章
- 基于 Vue 和 Vite
- 静态页面生成
- 默认主题美观
- 支持自定义主题

## 二、安装

```bash
npm add -D vitepress@latest
```

## 三、总结

通过 VitePress，可以快速搭建一个轻量、漂亮的个人博客。
